# 16 November 2026

## What we built

Prepared the latest Mac desktop release from committed main while preserving the workspace's intentionally removed hosted automation.

## What we fixed

Library cards now start their selected game on Mac instead of exiting before the game loads. A failed immediate launch keeps the Library open and displays an error. Local acceptance now continues through the prerelease notice and exercises the actual Library button callback, rather than only starting game modes directly.

Mac packaging accepts the preserved removal of workflow YAML files without restoring hosted automation. Any gameplay-source edit, staged change or untracked file still stops the build. Release provenance records the excluded workflow removals alongside the exact engine and game commits.

The native handoff check refreshes process status after discovering a new child, so a successful launch cannot be mistaken for an exit because of a stale process snapshot.

Four original-country flag slots now display the approved national flags instead of abbreviation tiles. Lebanon and all other flag pixels remain unchanged. Local release checks seal the atlas bindings and all sixteen flags at each display density.

## Key decisions

Keep release verification local and preserve existing work. Workflow removals do not change the packaged game; other dirty source remains ineligible for release.

## Breaking changes

None.

Six scope, binding, idempotence and optimization regressions pass. Shared web-generator default output is byte-identical to the prior version. Actual native arranged US and China visual fixtures were captured; ready original support-power icons are selected by the guarded UI-only adapter. Immutable-package tests remain a separate gate after committing.

# Frontline native menu — 15 October 2026

Selected source: first displayed proposal, Frontline, approved by the owner.
Original UI key art generated with the built-in ImageGen tool using our authored
vehicle render and actual Classic/RA2 captures as references. No EA promotional
art was used. The menu is implemented in C# OpenRA widgets; its controls are not
baked into the backdrop. Existing gameplay content and both mode profiles remain.

- backdrop.png: clean battlefield plate, generated by removing all UI from the approved source.
- controls.png: transparent generated wordmark and blank worn-cream button atlas.
- icons.png: transparent generated chevron and puzzle silhouettes from the approved source.

Generation prompts and reference remain under docs/frontline-menu-assets/.
Bundled fonts are Black Ops One and Chakra Petch, from google/fonts, with their
respective SIL Open Font Licenses in ../fonts/. Those files are local runtime resources.

Font sources (downloaded 15 October 2026):
- https://github.com/google/fonts/tree/main/ofl/blackopsone
- https://github.com/google/fonts/tree/main/ofl/chakrapetch

`tools/frontline-textures.py` adds transparent padding to meet the engine's
power-of-two texture requirement. It leaves all generated content pixels and
chrome coordinates unchanged. Original unpadded PNGs remain in the asset sources.

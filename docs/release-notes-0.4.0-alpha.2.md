# RTS AI 0.4.0-alpha.2 — standalone Windows update

One Windows game with **Classic / top-down** and **RA2 / isometric** modes. No owned Red Alert or Red Alert 2 installation is required. The website also provides the live isometric browser game.

This update brings the consolidated shared native/browser engine and the latest campaign and Classic rendering corrections into the Windows download:

- Campaign victory now completes secondary protection objectives before the last primary objective awards the win.
- All six campaigns in both modes expose Easy, Normal and Hard difficulty.
- Classic fog and shroud use project-made square-grid artwork.
- 16 country choices, including seven authored modern faction packs; native bots and optional local AI companion.

The EXE installer is per-user; a portable ZIP is also available. Select **No AI** for the first gameplay test. Local AI requires optional model downloads and appropriate hardware. This alpha is **unsigned**, with SHA-256 checksums published for every artifact. No macOS package is included; that follows on the owner's Mac.

Source acceptance includes 228 assisted campaign-condition runs and 160 roster matches. These do not replace human campaign playthroughs or competitive balance acceptance. Broader clean-OS, real camera/microphone, separate-device/network and Safari acceptance remain open. Classic uses the modern army on a rectangular grid; full historical Classic parity remains on the roadmap.

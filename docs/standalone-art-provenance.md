# Art provenance: the standalone build (Phase 3)

Date: 2026-10-07. This page covers the art the art agent made so the standalone build runs without Red Alert 2: the
shared modern base kit, the shared units and the effects. The per-file record is
`mods/rtsai/standalone/ART-PROVENANCE-STANDALONE.json`, written by RTSAI-Art `tools/standalone_art_record.py`. The
modern factions' own art is covered in [art-provenance.md](art-provenance.md); audio in
[audio-provenance.md](audio-provenance.md).

**[ran]** means a command was run and its output observed.

## Scope and summary

candidate committed in RTSAI-Art, and the record names that candidate and the RTSAI-Art commit holding it [ran:
`tools/standalone_art_record.py --check`]. The two sequence files are generated by the install commands from the

## How it is made

No image-to-3D and no generated concept pictures: every model is written as code.

- **Base kit and vehicles.** Each role is a procedural Blender model (bmesh boxes, prisms, wedges, cylinders, domes,
  trusses) authored in `base_kit_designs.py`, one shared design painted per faction. Blender Cycles (CPU) renders
  beauty, material-ID and shadow layers at 4x; Python reduces them, quantises each material class into its ramp of the
  shared `kitbase.pal` (player colour on 16-31), draws a 1 px contour and writes OpenRA TS SHPs. Buildings carry
  damaged and critical states, a build-up animation and overlay animations (crane, fans, doors, lamps, drill, dock,
  purifier). Vehicles have 32 facings with shadows; the AA track has a separate turret.
- **Faction paint.** One render per role with template colours; each faction's SHP differs only in the indices of its
  panel and accent ramps (`tools/palettes/<faction>.json` hues). Player colour is never baked in.
- **Engineer and operative.** Hand-authored segmented Blender models (one part per bone) rendered through the faction
  infantry route like every faction soldier, once per faction uniform, then mapped onto `kitbase.pal`. Cameos are
  portraits from the route's own cameo renderer.
- **Dog.** A skinned quadruped: anatomical volumes voxel-remeshed into one body on a 26-bone armature, posed per frame.
- **Effects.** `fx_forge.py` draws every frame from code: noise-textured spherical puffs (fire heat ramp, lit smoke
  with soft rims and an ordered-dither fade), sparks, debris, shock rings, splash crowns, arcs and glyphs, quantised to
  the project's own `anim.pal` or written as RGBA PNG sheets. Canvases are trimmed symmetrically to the content of
  all frames, so placement is unchanged and no empty margin ships.
- **Name bars.** Cameos and icons use Kenney Pixel (CC0 1.0); only the rendered pictures ship.

## Stock files: measured, never used

Original Red Alert 2 files were never an input. The routes read stock RA2 art only on the developer's machine
(RTSAI-Art `reference-local/`, ignored by git) to measure targets: on-screen size per role, value range, local
contrast, edge density, colour-block size, the effects' size envelopes and frame counts, and the cameo picture
statistics [ran: `base_kit.py gate`, `cameo_render.measure`, `fx_forge.py` calibration]. Gates passed at install: all
14 building roles and every cameo; the fragment check on every building, vehicle, infantry and dog frame.

## Reproduce

```
# RTSAI-Art (OpenRA-AI venv; Blender 5.2; CPU only; at most 3 Blender jobs at once)
python tools/base_kit.py build --look v2 --kits <roles>        # render + post; then cameos, gate, review
python tools/base_kit.py install --look v2 --mod <RTSAI-Mod> --kits cnst,powr,hpwr,refn,barr,weap,radr,airf,yard,dept,tech,sw1,sw2,wall
python tools/base_kit.py install-units --look v2 --mod <RTSAI-Mod> --kits mcv,harv,htk,sapc,lcrf,dog
python tools/kit_infantry.py models && python tools/kit_infantry.py route && python tools/kit_infantry.py cameos && python tools/kit_infantry.py kitbase
python tools/base_kit.py install-units --look v2 --mod <RTSAI-Mod> --kits engineer,spy
FX_CAND=fx-v2 python tools/fx_forge.py build && FX_CAND=fx-v2 python tools/fx_forge.py install --mod <RTSAI-Mod>
python tools/standalone_art_record.py --mod <RTSAI-Mod> --check
```

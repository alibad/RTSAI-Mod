# 16 November 2026

## What we built

Prepared the latest Mac desktop release from committed main while preserving the workspace's intentionally removed hosted automation.

## What we fixed

Library cards now start their selected game on Mac instead of exiting before the game loads. A failed immediate launch keeps the Library open and displays an error. Local acceptance now exercises the actual Library button callback, rather than only starting game modes directly.

Mac packaging accepts the preserved removal of workflow YAML files without restoring hosted automation. Any gameplay-source edit, staged change or untracked file still stops the build. Release provenance records the excluded workflow removals alongside the exact engine and game commits.

## Key decisions

Keep release verification local and preserve existing work. Workflow removals do not change the packaged game; other dirty source remains ineligible for release.
